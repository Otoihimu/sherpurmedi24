SherpurMedi24 — Clean Start Package

Folder structure:
index.html
assets/sherpurmedi24-logo.jpg
css/style.css
js/app.js

GitHub Pages upload:
1. Extract this ZIP on your computer.
2. Open your GitHub repository's main page (Code tab, main branch).
3. Click Add file > Upload files.
4. Upload the CONTENTS of this extracted folder, not the ZIP itself.
   Keep the assets, css and js folder structure intact.
5. Commit the upload.
6. In Settings > Pages, select Deploy from a branch, branch main, folder /(root), then Save.

The repository root must contain index.html, assets/, css/, and js/.
The header logo is loaded from assets/sherpurmedi24-logo.jpg.

Navigation displays one section/page at a time:
Home, Pharmacy Directory, How it Works, About.
Search and area filter are demo-only. The pharmacy listings are fictional.
No live medicine sales, prescription uploads, payments, orders, or delivery are active.
